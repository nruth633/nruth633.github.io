What it is

A course capstone board taken through the full design flow — schematic capture, component selection, layout, and export of fabrication-ready gerbers. Not a breadboard mockup: the output is the set of files a fab house needs to actually build the thing.

Custom footprints

Several parts had no usable stock symbol or footprint, so the project carries its own library built from the manufacturer datasheets — pad geometry, courtyard, and 3D models included. This is the part of board design that quietly eats the most time, and getting it wrong means a board that arrives unusable.
