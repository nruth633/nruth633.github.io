Why build it

Wiring an IMU onto a breadboard works right up until you need the same setup twice. Jumpers work loose, the sensor sits at a slightly different angle each time, and any orientation calibration you did last session is gone.

Putting the MPU6050 on a proper shield fixes the sensor in a known position relative to the board and makes the setup repeatable — you seat it on the UNO and it's the same rig as last time. That matters a lot for motion work, where the whole measurement is relative to how the sensor is mounted.

Design

Standard UNO header geometry so it stacks like any other shield, with the IMU broken out over I²C. Designed in KiCad with the schematic, board layout, component libraries, and documentation all kept in the project.

More detail coming. Layout decisions, I²C bus design, and assembly notes to be written up here.

Related work

The same MPU6050 sensor drives attitude estimation on the 3-wheel balancing robot — this shield was a useful place to get familiar with the part before it had to hold a robot upright.
